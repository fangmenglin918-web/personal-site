# 个人网页写法模板

参考：https://.me/ —— 。
用途：写自己的简历附加网页时，按这个结构和写法套用。

---

## 一、整体结构（自上而下 5 块）

| 区块 | 作用 | 原站对应 |
| --- | --- | --- |
| 1. 名字 + 视觉作品 | 第一屏建立"我是谁、我有什么品味" | 大字 FEI XIONG + 两张代表作图（建筑作品 & Transformer 结构图） |
| 2. 自我介绍（两段） | 第一段讲履历，第二段讲信念 / 想做的事 | P1 中英双语 |
| 3. 联系方式 | 降低联系门槛 | 邮箱、播客、微信 |
| 4. 经历时间线 | 可扫读的履历 | E1–E12，倒序，每条一句话 + 年份 |
| 5. 作品 / 链接 | 让人能"点进去验证" | W1–W7，每条一句话 + 外链 |

要点：**简介讲故事，时间线讲事实，作品区给证据**。三块的信息有重叠，但写法不同。

---

## 二、自我介绍：两段式公式

### 第一段：身份标签堆叠（硬信息，一口气读完）

公式：
> 我是【名字】，【学历 1】，【学历 2 + 稀缺性标注】。曾任【最强头衔】（括号列出负责的具体方向）；【第二个亮眼头衔】；【身份概括，如"连续创业者"】——【公司 A + 角色 + 领域】、【公司 B + 角色 + 领域】。

原站写法拆解：
- "Harvard 21'（MDes RR首个大陆录取本科生）" → **学历后面带一个"第一 / 唯一 / 首个"的稀缺性标注**
- "千问多模态产品负责人（包括图片/视频理解，实时视频通话，computer use）" → **头衔后括号列出具体负责的模块，避免头衔太空**
- "豆包founding PM" → **用 founding / 0→1 这类词强调从零开始**
- 创业公司后面加领域括号："（Spatial Intelligence）""（物理世界定制AI）" → **让陌生公司名也能看懂**

### 第二段：起点 + 主线 + 信念 + 邀请

公式：
> 【年份】在【地点 / 机构】开始我的【领域】旅程，而后我致力于【一句话主线】。我相信【对行业的判断 1】，【判断 2】，【判断 3】。我希望建立【想做的事】，也希望认识更多有趣的朋友。

原站写法拆解：
- **起点**："2019在Harvard和MIT开始我的Computer Vision旅程" → 给经历一个起点，把跨界经历串起来
- **主线**："打造以视觉为统一接口的交互新范式" → 把所有经历收拢成一句话，这是全站最重要的一句
- **信念**：用"我相信……"连续三个判断，体现思考深度，而不只是在罗列履历
- **结尾邀请**："也希望认识更多有趣的朋友" → 语气放软，引导对方联系

## 三、经历时间线：一条 = 标题 + 一句话 + 年份

### 标题格式
> 【公司 / 产品】，【具体职位】  ／  英文同构

- 写到**具体产品线**，不只写公司："豆包，Computer Use Agent负责人"，不写"字节跳动产品经理"
- 同一家公司的不同阶段**拆成多条**（原站豆包拆成 CUA、VLM 两条），显得经历更厚

### 描述句公式（一句话，以"我"开头）
> 我【动词：负责 / 从零打造 / 构建 / 部署】【具体东西】，【关键动作或设计】，【量化结果】。

原站例句：
- "我从零打造豆包图片理解，长视频理解，视频实时通话等功能入口；贡献X千万DAU" → 动词 + 范围 + 量级
- "我负责豆包CUA的产品，新增【办公任务】大入口，设计GUI/非GUI混合策略，本地优先" → 动词 + 上线了什么 + 关键设计决策
- "服务20+大型空间，1000+摄像头，45 万㎡；团队有多篇NeurIPS / IEEE；客户包括香港置地……" → **规模数字 + 团队背书 + 知名客户**三连

动词库：从零打造、负责、构建、设计、部署、上线、主导、0→1
数字库：DAU、用户数、规模（摄像头 / 面积 / SKU）、客户名、论文数

### 排序
- 倒序（最近的在最上面）
- 工作经历在前，教育在后
- 教育条目也要有一句话亮点（"首个录取""交叉注册 CS/ML 课程"），不要只写学校名

---

## 四、作品区：一条 = 名字 + 一句话 + 外链

公式：
> 【项目名】｜【一句话：做了什么 + 结果】｜【外链类型 ↗】

- 每个作品都配**可点击的外部证据**：公众号推文、飞书文档、播客主页
- 不只放工作项目，还放**个人项目**（播客、专栏），体现持续输出和自驱力
- 个人项目写清楚**怎么做的**："海外长文→双角色逐字稿→TTS→自动上架小宇宙，每天更新"，用流程体现能力

---

## 五、风格要点

1. **中英双语逐段对照**：中文在前，英文紧跟，英文不是直译，而是更地道的改写
2. **编号系统**（H7 / E1 / W1）：作品集 / 建筑图纸风格，有设计感，同时暗示建筑背景；用的话要和自己的背景契合
3. **第一屏放视觉作品**，不放大头照，用作品说明品味
4. **全站只有一条主线**：所有经历都往"视觉 × AI 交互"上靠，跨界背景反而成了卖点
5. **克制**：每条经历只写一句话，细节交给外链

---

## 六、避坑（原站存在的问题，自己写时注意）

- 中英文名、公司名前后要统一（原站"悉空 / 深空""PlaceInt / Place.Int"不一致）
- 时间重叠的经历要说明清楚是兼职、顾问还是在读期间，否则会被追问
- 内部业务数据（DAU 等）公开前先确认合规，可以写量级（"千万级"）而不写具体数
- "业界首个"这类绝对化表述要有把握，否则改成"最早一批"
- 不要留下没有内容的装饰性编号
- 微信等私人联系方式按需公开，投递时留邮箱即可

```
【第一屏：1–2 张代表作图】

  第一段：我是___，___学历（稀缺性标注）。曾任___（具体方向）；___；___。
  第二段：___年在___开始___旅程，而后我致力于___（一句话主线）。
         我相信___，___，___。我希望___，也希望认识更多有趣的朋友。
  （英文版同构）

联系：邮箱 / 作品平台 / 社交账号

E 经历（倒序）
  E1 公司·具体职位 ／ EN    年份
     我___（动词）___，___（关键设计），___（量化结果）。
  ...
  教育：学校·专业 + 一句亮点

W 作品
  W1 项目名 ／ EN    一句话（做了什么 + 结果）    外链 ↗
  ...（至少一个个人项目）
```
